# Braid

**Multi-Way Sync for photographers.** Braid keeps a Capture One session (or any folder) and every backup drive identical, whichever one you worked on last. You see every change before anything is written, and replaced files go to an `_Archive` folder, so nothing is lost by accident.

- **Multi-Way Sync** and **One-Way Backup**
- **Sync Check:** a full plan of what will be copied, updated and removed on every drive, before you start
- **Checksums:** every file is verified with xxHash64, with ASC MHL records on each drive and a PDF/CSV transfer report
- **Verify Drive:** re-reads a backup and proves it is intact
- **Built for shooting days:** files that arrive mid-sync are picked up, and unplugged drives catch up next time
- **Capture One aware:** open, rename and back up sessions safely

## Download

Get the latest version from [Releases](https://github.com/tonytrangit/braid/releases/latest) (or [download Braid 1.0.2 directly](https://github.com/tonytrangit/braid/raw/main/downloads/Braid-1.0.2.zip)). Unzip it and move **Braid** to your Applications folder.

The first time you open it, macOS may say it can't verify the developer. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. You only need to do this once. After that, Braid updates itself.

Requires macOS 14 Sonoma or later.
